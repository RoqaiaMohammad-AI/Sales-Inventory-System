# المتطلبات الوظيفية
## Functional Requirements

### 1. مقدمة

تحدد هذه الوثيقة الوظائف والخدمات التي يجب أن يوفرها نظام إدارة المبيعات والمخزون، وتستخدم مرجعاً أثناء تصميم النظام وتطويره واختباره.

تم تقسيم المتطلبات حسب الوحدات الوظيفية للنظام، مع إعطاء كل متطلب رمزاً تعريفياً لتسهيل تتبعه.

### 2. إدارة المستخدمين وتسجيل الدخول (User Management)

| الرمز | المتطلب | الوصف |
|---|---|---|
| FR-001 | تسجيل الدخول | السماح للمستخدم بالدخول باستخدام اسم المستخدم أو البريد الإلكتروني وكلمة المرور. |
| FR-002 | تسجيل الخروج | إنهاء جلسة المستخدم بشكل آمن. |
| FR-003 | إدارة المستخدمين | السماح للمدير بإضافة المستخدمين وتعديل بياناتهم وتعطيل حساباتهم. |
| FR-004 | إدارة الأدوار | تحديد دور المستخدم وصلاحياته. |
| FR-005 | حماية الصفحات | منع المستخدم من الوصول إلى الوظائف التي لا يمتلك صلاحية استخدامها. |

| الرمز | المتطلب | الوصف |
